# Инвентарь

Локальное приложение для macOS: вещи, места, люди, статусы и теги. Данные хранятся на этом Mac, без сети и облака.

- Язык интерфейса: русский.
- Минимальная macOS: 12.0. Сборка universal (Apple Silicon и Intel).
- Стек: Swift 6, SwiftUI с AppKit-мостами, GRDB 7.12.0, ZIPFoundation 0.9.20.

## Сборка и тесты

Нужен полный Xcode (проверено на Xcode 27.2, Swift 6.4.2).

```sh
swift build                  # сборка пакета
swift test                   # 277 тестов: ядро, платформа, UI-модели
xcrun swift-format lint --recursive --strict Sources Tests

# Проект Xcode генерируется из project.yml; после изменения целей:
xcodegen generate
xcodebuild test -project Inventory.xcodeproj -scheme InventoryApp -destination 'platform=macOS'
```

Release-сборка universal:

```sh
xcodebuild -project Inventory.xcodeproj -scheme InventoryApp -configuration Release \
  -derivedDataPath build-release -destination 'generic/platform=macOS' \
  ARCHS='arm64 x86_64' ONLY_ACTIVE_ARCH=NO build
lipo -info build-release/Build/Products/Release/Inventory.app/Contents/MacOS/Inventory
```

Запуск: `open build-release/Build/Products/Release/Inventory.app`.

## Где лежат данные

По умолчанию: `~/Library/Application Support/Inventory/`.

```
inventory.db        база SQLite (WAL)
photos/ thumbs/     фото вещей и мест
logs/app.log        журнал приложения
_safety/            копии перед миграцией и импортом, журнал операций
_tmp/               временные папки операций
.inventory.lock     блокировка папки (один процесс за раз)
```

Путь к папке и настройки интерфейса хранятся вне папки данных. В архив они не попадают.

## Экспорт и импорт (раздел «Данные»)

- **Экспорт.** Создаётся `Inventory-ГГГГ-ММ-ДД.inventory.zip`: `manifest.json`, `data.json` (все девять таблиц), `photos/`, `thumbs/`. Файл публикуется только после успешной упаковки.
- **Импорт.** Архив сначала проверяется: ZIP, манифест, версия формата, связи, наличие фото, лимиты распаковки. Затем нужно ввести число вещей из архива. Импорт полностью заменяет текущие данные.
- **Копия до импорта.** Перед заменой создаётся `_safety/before-import/`. Откат «Откатить последний импорт» доступен, пока копия есть.
- **Сбой.** Если замена или проверка не удались, данные возвращаются из копии автоматически.
- **Перенос папки.** «Перенести в другую папку…» копирует данные в пустую папку и переключает приложение. Старая папка остаётся нетронутой до вашего решения.
- **Открытие папки.** «Открыть другую папку…» переключает на существующее хранилище. Текущее хранилище закрывается только после успешного открытия нового.
- **Облачные папки.** Если папка находится в iCloud Drive, Dropbox, Google Drive или OneDrive, приложение предупреждает: синхронизация может мешать работе.

Протокол безопасной замены описан в `RECOVERY_PROTOCOL.md` (утверждён владельцем, перенесён из ThingsMap2).

## Напоминание о копии

Если экспорта не было или прошло больше 30 суток, в разделе «Данные» появляется напоминание. Напоминание можно отключить; настройка сохраняется между запусками.

## Настройки

Меню «Инвентарь → Настройки…»: папка данных, статусы по умолчанию (для новых вещей, при передаче, при возврате; только активные статусы) и переключатель напоминания.

## Ограничения

- Лимиты архива (D11): распакованный размер до 2 ГиБ, до 100 000 файлов, коэффициент сжатия до 100, `data.json` до 512 МиБ.
- Сборка не подписана и не нотаризована. Запуск на другом Mac: контекстное меню → «Открыть», либо `xattr -dr com.apple.quarantine Inventory.app`.
- Синхронизаторы (iCloud, Dropbox и т. п.) могут менять файлы вне блокировки приложения.
- Ручная проверка на Intel и на macOS 12 не выполнялась; см. `HANDOFF.md`.
