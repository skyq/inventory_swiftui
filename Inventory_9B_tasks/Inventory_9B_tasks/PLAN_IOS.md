# План: полная версия для iPhone (черновик, не утверждён)

Статус: ЧЕРНОВИК. Код не начат. Начинать только после подтверждения владельца.

## 1. Цель и границы

- Полная версия по функциям macOS: вещи, фото, места, люди, статусы, теги, поиск, история, передачи/возвраты, экспорт/импорт, откат, перенос папки данных, напоминание о копии.
- Устройство: iPhone 15 Pro Max и другие iPhone; минимум **iOS 26.0**. Тестовый телефон: iOS 26.6.2.
- Не входит: iPad-оптимизация, Mac Catalyst, iCloud-синхронизация, сеть, аналитика (как и на macOS, D-правила не меняются).

## 2. Решения, которые нужно утвердить

| # | Вопрос | Предложение |
|---|---|---|
| I1 | Минимальная iOS | 26.0 |
| I2 | Где хранятся данные | Контейнер приложения (`Application Support/Inventory`); экспорт архива — через «Файлы» (share sheet) |
| I3 | Смена «папки данных» | Заменяется на «Экспорт/Импорт» и «Перенос в Файлы»: внешний каталог через `fileImporter` с security-scoped доступом. Прямой выбор папки как на macOS не предлагается |
| I4 | Фото | `PhotosPicker` + камера (`UIImagePickerController` через мост или `PhotosPicker` с камерой); вставка из буфера через `UIPasteboard` (кнопка, не глобальный хоткей); drag and drop — только на iPad, на iPhone не делаем |
| I5 | Навигация | `NavigationStack` + `TabView` (Галерея / Места / Люди / Статусы / Теги / Данные); карточка вещи — экран, не боковая панель |
| I6 | Поиск | Строка `searchable` сверху; Cmd+K не нужен (клавиатурных сокращений как на Mac нет) |
| I7 | Хоткеи | Не добавлять; D09 относится к macOS |
| I8 | Бэкап-напоминание | Как на macOS (30 суток) |
| I9 | Облачные папки | Предупреждение остаётся для путей в iCloud Drive / «Файлы» |
| I10 | Подпись | Personal Team (7 дней) для личной установки; для раздачи друзьям — платный Apple Developer ($99/год) и TestFlight |

## 3. Что переиспользуем без изменений

- `InventoryCore` (ядро, миграции, поиск, экспорт/импорт, восстановление, `RECOVERY_PROTOCOL.md`) — 216 тестов; убрать или заменить всё, что тянет AppKit/`Darwin`-специфику (`flock`, `sysctl` в бенчмарке — только в macOS-таргете).
- GRDB 7.12.0, ZIPFoundation 0.9.20 — поддерживают iOS.
- Модели `InventoryUI` (`AppModel`, `GalleryModel`, `PeopleModel`, …) — переносятся, если не завязаны на `NSImage`/`NSOpenPanel`.

## 4. Что переписываем

| Область | macOS сейчас | iOS |
|---|---|---|
| Окно/каркас | `HSplitView`, `NSApp` | `NavigationStack`, `TabView` |
| Изображения | `NSImage`, `NSBitmapImageRep` | `UIImage`, `CGImage` (ImageIO общий) |
| Диалоги | `NSOpenPanel`, `NSSavePanel` | `fileImporter`, `fileExporter`, `PhotosPicker` |
| Буфер | `NSPasteboard` | `UIPasteboard` |
| Drag & drop | `NSItemProvider` в NSView | только iPad, не в MVP iPhone |
| Настройки | `Settings {}` сцена | экран «Настройки» внутри `TabView` |
| Тесты | `InventoryAppTests` (XCTest/Testing) | те же модели, без AppKit |

## 5. Этапы

- **IOS.01** Таргет `InventoryApp-iOS` в `project.yml`, iOS 26.0, Personal Team, пустой запуск на телефоне. Приёмка: приложение открывается на iPhone.
- **IOS.02** Вынести AppKit из `InventoryCore`/`InventoryUI` в платформенный слой; `swift build` для iOS (`-destination 'generic/platform=iOS'`) собирается. Приёмка: ядро и модели собираются для iOS, тесты macOS проходят.
- **IOS.03** Хранилище в контейнере: создание, открытие, блокировка, `RECOVERY_PROTOCOL` на iOS (fsync, `rename`, сбой питания). Приёмка: тесты восстановления проходят на симуляторе.
- **IOS.04** Галерея, поиск, карточка вещи на экранах; фильтры — листом. Приёмка: 500 вещей на телефоне, карточка < 200 мс (замер).
- **IOS.05** Вещи: создание/редактирование, фото из `PhotosPicker`/камеры, обработка HEIC/EXIF.
- **IOS.06** Места, люди, статусы, теги, передачи/возвраты, история.
- **IOS.07** Данные: экспорт в «Файлы», импорт с подтверждением числа вещей, откат, перенос, напоминание, предупреждение об облаке.
  - Скрытие вещей по статусам (добавлено владельцем): вещи с выбранными статусами (например, «Утеряна») не показываются в галерее и поиске по умолчанию; фильтр «Показать скрытые» их возвращает. Ядро: настройка скрытых статусов и условие в `GalleryQuery`; iOS и macOS: переключатель в фильтрах галереи. Вещи не архивируются, данные не меняются.
- **IOS.08** Настройки, локализация, Dynamic Type, VoiceOver (минимум), тёмная тема.
- **IOS.09** Замеры на iPhone 15 Pro Max и iOS 26.6.2: запуск, галерея, поиск, экспорт/импорт на 500 вещах. Сборка IPA для установки.
- **IOS.10** Приёмка владельцем.

Оценка: IOS.01–IOS.03 — основная технически рискованная часть (ядро на iOS). Точную оценку дам после IOS.02.

## 6. Риски

- Файловая система iOS и `fsync`/`rename` семантика должны подтвердиться тестами на устройстве, а не предполагаться.
- Personal Team: установка действует 7 дней; для постоянного использования нужен платный аккаунт.
- Размер фото и архива (157 МБ на 500 вещей) на телефоне: проверить память при импорте.
- `Darwin`/`flock` в `StorageLock`: на iOS поведение проверить отдельно.
