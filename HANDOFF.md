## Что уже работает

- Статусы: создание, переименование, архив/восстановление, регистронезависимая уникальность среди активных и архивных, `sort_order` без ручного порядка. Архивация статуса из `default/transfer/return` требует активную замену и меняет все три настройки одной транзакцией; вещи сохраняют архивный статус.
- Настройки статусов: `StatusSettingsService.settings/update`, только существующие активные статусы; при сбое не меняется ни одна из трёх настроек.
- Люди: создание/редактирование (имя, телефон, заметка), архив/восстановление, предупреждение дубля с обязательным `duplicateConfirmed`, отсутствие удаления. Активные предлагаются для новых передач; переименование меняет отображение старой истории по id.
- Действия с вещью одной транзакцией: `changeStatus`, `give`, `returnItem`. Даты только из `Clock`; количество не меняется; смена статуса и transfer пишутся раздельно; при ошибке откатываются transfer, `status_changes`, место и `items.updated_at`.
- D02: при передаче с уже текущим статусом transfer пишется, `status_changes` — нет. D03: архивный человек допустим для возврата только если он есть в истории передач этой вещи. D04: `keep`, `clear` и `place` — разные намерения; в диалоге возврата по умолчанию «оставить текущее место». D08: новый человек создаётся в транзакции передачи и не появляется при отмене/сбое. D12: при равных миллисекундах передача/возврат выше смены статуса, затем id ASC.
- История: единая лента вещи (`status_changes` + `transfers`), новые сверху, текущие имена статусов и людей по id; лента человека с переходом к вещи. Только чтение — методов update/delete нет, SQL-триггеры неизменности продолжают действовать.
- Теги: `listWithCounts`, переименование, объединение с итоговым именем и переносом связей без дублей, удаление со снятием со всех вещей и возвратом `TagDeletion` (itemId + count). Конфликт с третьим тегом отклоняется; сбой откатывает связи.
- Раздел «Статусы»: активные по умолчанию, переключатель архивных, создание/переименование через sheet, архивация с выбором замены, восстановление, три picker’а настроек.
- Раздел «Люди»: список с архивными по переключателю, форма, подтверждение дубля, карточка с телефоном/заметкой, архив/восстановление и история передач; клик по вещи открывает её правую панель в галерее.
- Раздел «Теги»: список с количеством вещей, сортировка имя/количество, inline rename с предложением объединения при коллизии, merge с итоговым именем, удаление с подтверждением и числом вещей.
- Карточка вещи: меню «Действия» (сменить статус, передать, вернуть, редактировать), диалоги с комментарием, историей и подсказкой §6.6; после успеха обновляются карточка, галерея и история человека.
- Форма вещи по-прежнему не меняет статус: текст `items.statusReadOnly` обновлён, смена статуса идёт только отдельным действием.
- Поиск в toolbar остаётся заглушкой этапа 4; новых горячих клавиш нет (Cmd+K/N/W/Esc).
